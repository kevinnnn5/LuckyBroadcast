# LuckyBroadcast
A simple broadcast and countdown plugin.
----
Commands :
- /broadcast <messages> | Announce an messages with custom prefix
- /maintain <duration> | Announce an Maintaince messages with custom prefix and countdown ( REQUIRE MAINTAINCE PLUGIN )
- /restarting <duration> | Announce an Restarting messages with custom prefix and countdown
----
Requirement :
- [Maintaince](https://www.spigotmc.org/resources/maintenance-bungee-and-spigot-support.40699/) | Maintaince System with Whitelist, Custom MOTD and Others!
